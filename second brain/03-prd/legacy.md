# PRD Versioning & Changelog

A compact log of how PRDs in this folder have evolved over time. PRDs are living documents; this is where we write down what changed and why so we can answer "when did we decide X?" later.

## Conventions

- Use semver-flavored slice numbers: `1.0.0` is the first shipped slice; `1.0.1` is the next compatible slice; `2.0.0` is a breaking redesign.
- Each PRD links here under its "Further Notes" section.
- Add an entry at the top whenever a PRD is changed materially (scope, decisions, or success metrics).
